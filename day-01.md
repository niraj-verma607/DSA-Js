# 🚀 Programming Fundamentals Cohort (Curated Practice Sheet)

A **curated list of beginner programming problems** designed to build
strong fundamentals in problem solving.\
The problems progress gradually from **basic arithmetic → loops → number
logic → intermediate algorithms**.

Each problem includes a **clear description and example** similar to
coding platforms like LeetCode.

---

# 🟢 Level 1 --- Basic Arithmetic & Geometry

## 1. Area of a Circle

**Description**\
Given the radius of a circle `r`, return the area of the circle.

Example\
Input

    r = 3

Output

    28.27
