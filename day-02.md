# 🚀 DSA Practice Sheet

## Loops + Conditionals (Beginner → Intermediate)

This sheet focuses on building **logic using only loops and
conditionals**.

Skills trained: - 🔁 Loops (`for`, `while`) - 🔀 Conditional
statements - 🔢 Digit manipulation - ➗ Basic math reasoning

No arrays, no strings, no advanced structures.

------------------------------------------------------------------------

# 1️⃣ Count Digits

## Problem

Given an integer `n`, count the number of digits in it.

Example Input: 12345

Output: 5

------------------------------------------------------------------------

# 2️⃣ Reverse a Number

## Problem

Given a number `n`, reverse its digits.

Input: 1234

Output: 4321

------------------------------------------------------------------------

# 7️⃣ Count Even Digits

# 8️⃣ Palindrome Number

## Problem

Check whether a number reads the same forward and backward.

Input: 121

Output: YES

# 9️⃣ Armstrong Number

## Problem

A number is Armstrong if the sum of cubes of its digits equals the
number.

Example: 153 1³ + 5³ + 3³ = 153

Output: YES

------------------------------------------------------------------------

## Problem

# 1️⃣6️⃣ Digital Root

## Problem

Repeatedly sum digits until a **single digit remains**.

Input: 9875

Steps: 9+8+7+5 = 29 2+9 = 11 1+1 = 2

Output: 2
